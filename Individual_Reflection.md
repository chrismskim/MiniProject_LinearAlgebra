# Individual Reflection

In this individual project, I completed both the Data Engineering and Machine Learning tasks. 
I worked on cleaning the Online Retail II dataset, building a sparse customer-product matrix, implementing a recommendation system using Truncated SVD, and comparing its performance with PCA.

The most challenging parts of this project were **data cleaning and implementing the recommendation system**. During data cleaning, I had to handle cancelled transactions, missing customer IDs, invalid quantities, and non-product codes. I learned that these decisions are important because the quality of the data directly affects the results of the model.

Implementing the recommendation system was also challenging. I had to understand how to use the reduced customer and product representations to generate recommendations while excluding products that customers had already purchased. Evaluating the recommendations against a best-seller baseline also helped me understand how to measure model performance.

Through this project, I learned how linear algebra techniques such as PCA and SVD can be applied to real-world problems. If I worked on this project again, I would improve the data cleaning process and experiment with different recommendation methods and purchase-value representations.
